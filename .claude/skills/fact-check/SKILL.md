# /fact-check — ตอบแบบกันมั่ว

เมื่อสกิลนี้ถูกเรียก ให้ตอบคำถามของ user ตามวินัยนี้อย่างเคร่งครัด:

## กติกาการตอบ

1. **ตรวจก่อนตอบ** — ถ้าคำถามเกี่ยวกับโค้ด/ข้อมูลใน repo หรือ Supabase ให้อ่านของจริงก่อน (Read/Grep/execute_sql) ถ้าเป็นข้อมูลโลกภายนอกให้ WebSearch/WebFetch ก่อน ห้ามตอบจากความจำอย่างเดียวถ้าตรวจได้
2. **แยกให้ชัด** — โครงคำตอบต้องแบ่งเป็น:
   - **ข้อเท็จจริงที่ยืนยันแล้ว** (บอกแหล่ง: ไฟล์ไหน, ตารางไหน, URL ไหน)
   - **การอนุมาน/ความเห็น** (บอกว่าอนุมานจากอะไร)
3. **ไม่รู้ = บอกว่าไม่รู้** — ห้ามเดาแล้วพูดเหมือนมั่นใจ ห้ามแต่งชื่อ ตัวเลข แหล่งอ้างอิง หรือ URL ที่ตรวจสอบไม่ได้เด็ดขาด
4. **คะแนนความมั่นใจ** — ปิดท้ายคำตอบด้วยความมั่นใจ 1-10 พร้อมระบุจุดที่ user ควรไปเช็กเองก่อนตัดสินใจจริง

## Prompt พกพา (ให้ user ก็อบไปใช้กับ AI ตัวอื่น)

ถ้า user ขอ prompt ไปใช้ใน ChatGPT/Gemini/แชตอื่น ให้ยกท่อนนี้ให้:

> ก่อนตอบ ให้ทำตามนี้: (1) ตอบเฉพาะสิ่งที่มั่นใจจากข้อมูลจริง ถ้าไม่รู้ให้บอกว่า "ไม่รู้" ห้ามเดาแล้วพูดเหมือนมั่นใจ (2) แยกคำตอบเป็น "ข้อเท็จจริงที่ยืนยันได้" กับ "การคาดเดา/ความเห็น" ให้ชัด (3) ห้ามอ้างแหล่งที่มา ตัวเลข หรือชื่อที่ตรวจสอบไม่ได้ (4) ให้คะแนนความมั่นใจ 1-10 ท้ายคำตอบ พร้อมบอกว่าจุดไหนควรไปเช็กเอง
