# /scrape — ดึงข้อมูลเว็บฟรี

รับ URL + สิ่งที่ user อยากได้ แล้วดึงข้อมูลออกมาเป็นโครงสร้างที่ใช้ต่อได้ทันที

## ขั้นตอน

1. **ลอง WebFetch ก่อน** — เร็วสุด ใส่ prompt ระบุชัดว่าจะสกัดฟิลด์อะไร (ชื่อ, ราคา, ลิงก์, ฯลฯ)
2. **ถ้าโดน 403/บล็อก bot หรือหน้าเป็น JavaScript ล้วน** — ใช้ Chromium ที่ติดตั้งไว้แล้วผ่าน Playwright (`executablePath: '/opt/pw-browsers/chromium'`) เขียนสคริปต์สั้น ๆ ใน scratchpad: เปิดหน้า รอโหลด ดึง `innerText` หรือ selector ที่ต้องการ
3. **หลายหน้า/pagination** — วนลูปใน สคริปต์เดียว ใส่ delay 1-2 วินาทีต่อหน้า อย่ายิงถี่
4. **ส่งมอบ** — สรุปเป็นตาราง markdown ในแชต + ถ้าข้อมูลเยอะให้เขียนเป็นไฟล์ CSV แล้วส่งด้วย SendUserFile

## กติกา

- เฉพาะหน้าเว็บสาธารณะ ไม่ล็อกอิน ไม่ข้าม paywall ไม่หลบ CAPTCHA
- อย่า scrape ข้อมูลส่วนบุคคล (ชื่อ-เบอร์-ที่อยู่ลูกค้าคนอื่น)
- ถ้าโดเมนโดน network policy ของเซสชันบล็อก (proxy CONNECT 403) ให้บอก user ตรง ๆ ว่าเข้าไม่ได้ อย่าพยายามอ้อม policy
- ระบุที่มา + เวลาที่ดึงไว้ในผลลัพธ์เสมอ เผื่อข้อมูลเปลี่ยน

## เคสที่ใช้บ่อยกับ LLOOP

- เทียบราคาเช่าชุด/ค่ามัดจำของร้านคู่แข่ง → ตาราง: ร้าน, รุ่นชุด, ราคาเช่า, มัดจำ, เงื่อนไข
- ดูเทรนด์ชุดจากหน้า new arrivals ของแบรนด์ → รายการ: ชื่อรุ่น, สี, ราคาขาย (ไว้ประเมินราคาเช่า)
- รวมรีวิว/เรตติ้งร้านเช่าชุดจากหน้า public
