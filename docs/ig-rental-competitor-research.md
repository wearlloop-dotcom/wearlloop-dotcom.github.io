- **ไม่ใช้ triptych (ภาพเดียวตัด 3 ช่อง) และไม่ใช้ checkerboard เลย** — ความต่อเนื่องมาจากฉาก+โทนสีเดียวกันทั้งบล็อก ไม่ใช่กลไกสลับช่อง
- การ์ดกราฟิก 2 ใบติดกัน = เกิดน้อยมาก เฉพาะช่วงประกาศเท่านั้น
- Reels แทรก ~1-2 ต่อแถว 5 ช่อง (close-up ผ้า, live-talk ถือไมค์แดงสไตล์แถลงข่าว — gimmick ประจำแบรนด์, BTS)
- ทุกรูปสัดส่วน **4:5 แนวตั้ง** เท่านั้น

## ค. ระบบการ์ด 10 แบบของ lookbook

1. **Title card** — รูปคีย์วิชวล + ชื่อคอลเลกชัน script ขาว + logotype
2. **Lineup/Identity card** — พื้นครีม สไตล์หน้านิตยสาร นางแบบไดคัท 5-13 ลุค + เลขกำกับ + แคปชันจิ๋ว (เวอร์ชัน recap แปะตรา SOLD OUT)
3. **Collage 9-16 ช่อง** — โพลารอยด์/คอนแทคชีท
4. **Sold out card** — ตัวหนังสือขาวทับรูป หรือตรายางแดงเอียง + เวอร์ชันอารมณ์ script ("Sold out in a flash!")
5. **Calendar card** — LIVE CALENDAR พื้นครีม + แดง / ตารางเดือนจริงแปะสติกเกอร์วันอีเวนต์
6. **Announcement card ธีมตามคอลเลกชัน** — ซองจดหมายบนผ้าสก็อต, ใบเสร็จมีบาร์โค้ด, นาฬิกาเข็มเชอร์รี่ (ทำ props ประกาศให้เข้าธีมเสมอ)
7. **Pop-up store card** — พื้นชมพู + line-art/3D isometric ตึกห้าง
8. **Launch/Live card** — "FIRST LIVE! ON LAZADA 20:00" condensed ขาวทับรูป
9. **Search-bar/meme card** — ช่องค้นหา IG ปลอม สร้าง hype แบบ playful
10. **Free gift/Giveaway card**

## ง. ระบบสี

- **สีแบรนด์คงที่ 2 สี: ชมพู blush (~#F6DAD2) + แดงเชอร์รี่ (~#E8442A)** — การ์ดฟังก์ชันทุกใบใช้คู่นี้ตลอด ไม่ว่าบล็อกรอบข้างโทนอะไร = "หมุดสี" ที่เป็นลายเซ็นแบรนด์ทั้งฟีด
- Palette รูปถ่ายเปลี่ยนอิสระตามบล็อก (เขียวสวน, เหลืองเนย, แดง Hello Kitty, เขียวขวด Paperdoll, ชมพูหม่นคอร์ตเทนนิส...)
- เทคนิคเปลี่ยนบล็อกไม่สะดุด: (1) บล็อกถัดไปมีสีร่วมอย่างน้อย 1 สี — ครีม/ชมพูเป็นสะพานเกือบตลอด (2) คั่นด้วยแถว street snap โทนกลาง (3) grade ภาพฟิล์มอุ่นเหมือนกันหมดทุกบล็อก

## จ. Typography — ล็อก 3 ฟอนต์

1. **Script ลายเซ็น** (หางตวัด สไตล์ Snell) — ชื่อคอลเลกชัน + ประโยคอารมณ์ สีขาวเมื่อทับรูป
2. **Sans ตัวพิมพ์ใหญ่ เว้นช่องไฟกว้าง น้ำหนักบาง** — logotype ใช้เป็นลายน้ำเกือบทุกรูป (ตำแหน่งยืดหยุ่นตามที่ว่างของภาพ)
3. **Condensed หนา** (สไตล์ Bebas) — การ์ดฟังก์ชันทั้งหมด: SOLD OUT, POP UP STORE, ตัวเลขใหญ่

## ฉ. การถ่ายรูป

- **หนึ่งบล็อก = หนึ่งโลเคชันจริง ถ่ายยกเซ็ตวันเดียวจบ** — ฉากคือตัวสร้างเอกภาพ ไม่ใช่เทมเพลต
- ระยะ: เต็มตัว ~50% / ครึ่งตัว / close-up ดีเทล ~10% / flat lay ~8%
- นางแบบ: เดี่ยว ~55-60%, คู่ ~25% (ท่าอินเทอร์แอกทีฟ), กลุ่ม ~5% — **ใช้หน้าเดิมวนซ้ำ ~5-6 คนจนเป็น "คาแรกเตอร์ประจำบ้าน"**
- Props เข้าธีมจริงจัง (เชอร์รี่จริง, แร็กเกต, สุนัข, ราวตากผ้าแขวนสินค้ากลางสวน = ภาพ signature ที่ทำซ้ำทุกบล็อก)
- โทนฟิล์มอุ่น แสงธรรมชาติ + แทรกภาพ candid มือถือพักสายตา (ฟีดไม่ "เนี้ยบจนไกลตัว")

## ช. สูตรปฏิบัติ 8 ข้อสำหรับ LLOOP

1. **ทำบล็อกละ 12-21 โพสต์ (4-7 แถว)** — บล็อกของร้านเช่า = ธีมโอกาสใส่: "ชุดรับปริญญา", "เพื่อนเจ้าสาว", "ปีใหม่/gala", "สงกรานต์ผ้าไทย" ถ่ายยกเซ็ตวันเดียวในโลเคชันเดียว นางแบบ 1-2 คนวนซ้ำให้เป็นหน้าประจำร้าน
2. **โครงบล็อก**: แถวแรก title card (รูปสวยสุด + ชื่อธีม script + โลโก้ LLOOP) → กลางบล็อกแถวละ "รูปเดี่ยว + รูปเดี่ยว/คู่ + text-tile" → กลางบล็อกใส่ lineup card รวมทุกชุดพร้อมรหัส → จบด้วย recap lineup แปะตราสถานะ
3. **แปลการ์ด lookbook เป็นบริบทเช่า**:
   - SOLD OUT → ตรา **"FULLY BOOKED / คิวเต็ม"** (FOMO แบบเดียวกัน)
   - RESTOCK → **"คิวว่างแล้ว / ชุดกลับเข้าคลัง"**
   - LIVE CALENDAR → **ปฏิทินคิวเช่ารายเดือน** (ไฮไลต์ช่วงรับปริญญา ม.ต่าง ๆ — เหมาะกับธุรกิจเช่ามากเพราะลูกค้าคิดเป็น "วันงาน")
   - ANNOUNCEMENT ticket → กติกาเช่า/รอบส่งซัก ทำเป็น props จริงเข้าธีม (แท็กซักแห้ง, hang tag)
   - POP UP card → การ์ดจุดรับ-คืนชุด/นัดลอง
4. **เรื่องราคา (จุดที่ต้องบาลานซ์ — lookbook ไม่โชว์ราคาบนกริดเลย)**: รูป hero ห้ามมีราคา (มีแค่ลายน้ำเล็ก) → รวมราคา+รหัสชุด+เงื่อนไขไว้บน **lineup card** เป็นตัวอักษรเล็กใต้แต่ละลุค + ราคาเต็มใน caption ทุกโพสต์ → กริดสวยแบบนิตยสาร แต่ลูกค้าหาข้อมูลได้ใน 1 แตะ
5. **สีแบรนด์**: เลือกคู่สี LLOOP 2 สี ใช้กับการ์ดฟังก์ชันทุกใบตลอดไป — palette รูปถ่ายเปลี่ยนตามธีมบล็อกได้อิสระ ระหว่างบล็อกคั่นด้วยแถว **รูปรีวิวลูกค้าจริง** โทนกลาง 1 แถว (แทน street snap + ได้ social proof แถม)
6. **ฟอนต์**: ล็อก 3 ตัว — script (ชื่อธีม), sans เว้นช่องไฟ (ลายน้ำ LLOOP), condensed หนา (การ์ดสถานะ) — ห้ามออกนอกชุด
7. **Pinned 3 ช่อง**: (1) title card ธีมประจำฤดู (2) การ์ด "วิธีเช่า 4 ขั้นตอน" (3) ปฏิทินคิวเดือนปัจจุบัน / **Highlights** แยกตามธีมชุด + "How to rent/FAQ" ปกรูปจริง
8. **ข้อควรระวัง**: ทุกรูป 4:5 เท่านั้น / อย่าวางการ์ด 2 ใบติดกัน (ยกเว้นประกาศคู่โดยตั้งใจ) / การ์ดทุกแบบต้อง "อยู่ตระกูลเดียวกัน" ด้วยสี+ฟอนต์ / **ตัวคูณสำคัญสุดคือวินัยถ่ายยกเซ็ต — ถ้าถ่ายชุดใครชุดมันคนละฉากคนละแสง ต่อให้ก็อปการ์ดครบระบบก็ไม่ออกมาเป็นแบบนี้**

## บทวิเคราะห์รวม — Pattern ที่เจอทุกร้าน / เกือบทุกร้าน

### สิ่งที่เป็นมาตรฐานตลาด (ควรมีให้ครบ)
1. **IG = แคตตาล็อก, LINE OA = จุดปิดการขาย** — ทุกร้านใช้ลิงก์ lin.ee ใน bio, บางร้านปิด DM ไปเลย
2. **ข้อมูลครบจบในรูปเดียว** — แบรนด์ / รหัสหรือชื่อรุ่น / ไซซ์+สัดส่วนจริง (นิ้ว) / ราคา 3 ขั้น / เงื่อนไขมัดจำ ฝังบนการ์ด ไม่พึ่งแคปชัน
3. **Template การ์ดนิ่งทั้งฟีด** — โทนครีม/เบจ/พาสเทล ฟอนต์ serif ทุกร้านหน้าตาไปทางเดียวกันหมด
4. **โครงราคา 3 ขั้น** — ส่วนใหญ่ 1/3/5 วัน (rent.chom ใช้ 1/2/3, unikko ใช้ 3/5) ส่วนต่างขั้นละ 50–100฿ คงที่ จำง่าย
5. **รูปคนใส่จริง ไม่ใช่ชุดแขวน** — ส่วนมากเป็น lookbook ของแบรนด์ต้นทาง + รูปลูกค้าจริง
6. **Highlight ใช้เป็น navigation** — แบ่งตามสีชุด (hera, rentfor.moment) หรือตามแบรนด์ (unikko, rent.chom) + อัลบั้ม Review แยกเสมอ
7. **Pinned posts = กฎการเช่า + โปรโมชัน + วิธีสั่ง**
8. **รีวิวแลกส่วนลด** — hera ลด 10%, rentfor.moment ลด 15% เมื่อโพสต์+แท็ก

### จุดตัดสินใจเชิงกลยุทธ์ที่แต่ละร้านเลือกต่างกัน
| ประเด็น | ทางเลือก A | ทางเลือก B |
|---|---|---|
| มัดจำ | ไม่เก็บเลย เป็นจุดขาย (closetcode, rent.chom) | เก็บสเกลตามราคาชุด (unikko 1,000–4,500) |
| ตลาด | แบรนด์ไอจี/เวียดนาม หลักร้อย (closetcode, rent.chom, hera) | แบรนด์ไทยพรีเมียม+luxury หลักพัน (unikko) |
| การนับวัน | นับเฉพาะวันใส่จริง ไม่นับวันขนส่ง (hera, rent.chom) | นับตามช่วงเช่า 3/5 วันรวม (unikko) |
| Loyalty | แต้มตามยอดบาท (hera 1฿=1แต้ม) | แต้มตามครั้ง (rentfor.moment ครบ 8 ฟรี 1) |

### ไอเดียที่น่าหยิบมาใช้กับ LLOOP
- **สูตรตั้งราคาของ unikko: ค่าเช่า 3 วัน ≈ 10% ของราคาช็อป + โชว์ราคาช็อปบนการ์ดเป็น anchor** ทำให้ลูกค้ารู้สึกคุ้มทันที (TAPA ก็ใช้วิธีโชว์ "Price เต็ม" คู่ราคาเช่าเหมือนกัน — เป็น pattern ของร้านที่โต)
- **ระบบรหัสชุดของ rent.chom (prefix แบรนด์ + เลขรัน)** — ตรงกับแนวคิด garment passport ของเราอยู่แล้ว ใช้รหัสเป็นตัวอ้างอิงตอนจองผ่าน LINE (TAPA ก็มีรหัสมุมการ์ดทุกใบ)
- **Ecosystem ของ hera**: บัญชีเครือข่าย (สูทผู้ชาย/กล้อง) + โปรคู่รักข้ามร้าน + double-date campaign ทุกเดือน + ประกาศวันหยุดเป็นระบบ — TAPA ก็แตกบัญชีลูกเช่ากล้อง (@tapadigirent.bs) เหมือนกัน = "เช่ากล้องคู่ชุด" เป็นสูตรที่ตลาดพิสูจน์แล้ว 2 ร้าน
- **การนับวันแบบ hera** (นับเฉพาะวันใส่ ไม่นับวันขนส่ง) เป็น friction-killer สำหรับลูกค้าต่างจังหวัด
- **โปรรีวิวแลกส่วนลด** — ได้ UGC + social proof ราคาถูก ทุกร้านที่โตใช้วิธีนี้ (TAPA สะสม highlight รีวิวถึงชุดที่ 12)
- ร้านที่ follower เยอะสุด (unikko 32.4K) คือร้านที่**เล่นตลาดบน มีมัดจำ** — แปลว่า "ไม่มีมัดจำ" ไม่ใช่เงื่อนไขจำเป็นของการโต แต่เป็นตัวลด friction ของตลาดล่าง
- **โครงการรัฐ "ไทยช่วยไทย พลัส 60/40"** — TAPA เข้าร่วมแล้วและโปรโมตเป็นโพสต์บนสุด ควรเช็คว่า LLOOP เข้าเกณฑ์สมัครได้ไหม (ลดราคาหน้าบ้าน 40% โดยรัฐช่วยจ่าย = ตัวเร่งยอดแรง)
- **ตลาดเมืองท่องเที่ยวแบบ TAPA** — เช่าชุด+บิกินี+กล้อง+เสื้อ F1 ตามกระแส สำหรับนักท่องเที่ยว "มาถ่ายรูป" เป็น segment ที่ต่างจากเช่าไปงาน — ถ้า LLOOP จะขยาย ลองคิดแบบ location-based
- **จากเครือ Lookbook (แบรนด์ขาย — ต้นแบบ branding)**: grid แบบนิตยสารคุมโทนต่อคอลเลกชัน, ตั้งชื่อชุดเป็นชื่อคน (จำง่าย+พรีเมียมกว่ารหัส — ใช้คู่รหัสได้), บันเดิลเพื่อนเจ้าสาวลดตามจำนวนคน (4 คน -10% / 8 คน -15%), ของแถมมีโลโก้ (ถุงคลุมชุด), sold-out marketing, มาสคอต/IP

## ง. เหตุผลเชิงการตลาด (ทำไมพอร์ตนี้ "ทำเงินง่าย")

1. **กลุ่ม 1 คืนทุนเร็วสุด**: ชุด 1,500 บาท เช่า 350/รอบ → คืนทุน 4-5 รอบ ที่เหลือคือกำไร — และเป็นแบรนด์ที่ลูกค้าค้นหาอยู่แล้ว (search ตามชื่อแบรนด์ = การตลาดฟรี)
2. **กลุ่ม 2 คือออเดอร์ก้อนใหญ่**: hera พิสูจน์แล้วว่างานหมู่คือ segment ที่ทำเงินสุด (ออเดอร์เดียว = 5-15 ชุด) และตรงกับธีมบล็อกแรก "เพื่อนเจ้าสาว/รับปริญญา" ในแผนคอนเทนต์พอดี
3. **กลุ่ม 3 คือหน้าร้าน**: unikko (follower เยอะสุด 32.4K) สร้างแบรนด์จาก Self-Portrait/Kemissara — hero pieces ทำให้ร้านดู "พรีเมียม" แล้วลากลูกค้ามาเช่ากลุ่ม 1 ที่ margin ดี
4. **โชว์ราคาช็อปเป็น anchor ทุกการ์ด** (สูตร unikko/TAPA/suummery): "Shop 21,500 → เช่า 2,000" ทำให้ลูกค้ารู้สึกคุ้มทันที
5. **ไซส์ L-XL 10 ตัวคือ blue ocean เล็ก ๆ**: คู่แข่งเกือบทุกร้านสต็อก S เท่านั้น — ประกาศ "ครบไซส์" ใน bio แบบ hera ได้เลย
6. **กระจายความเสี่ยง**: ไม่มีกลุ่มไหนเกิน 40% ของพอร์ต ถ้าหมวดไหนไม่หมุนใน 60-90 วัน โยกงบรอบถัดไปได้
