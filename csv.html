คู่มือ · ทีละขั้น

วิธีใช้งาน CSV ชุด

ส่งออก → แก้ในชีต → นำเข้ากลับ · เพิ่มชุดใหม่และใส่รูปได้ในไฟล์เดียว

ขั้น 1

โหลด template ว่าง

กด โหลด template ว่าง จะได้ไฟล์ lloop_template.csv ที่มีหัวคอลัมน์ครบ + แถวตัวอย่าง 1 แถว เปิดด้วย Excel / Google Sheets ได้ (รองรับภาษาไทย)

ขั้น 2

กรอกข้อมูลลงชีต

พิมพ์ข้อมูลชุดทีละแถว · ฟิลด์หลายค่า (occasion_tags, styling_tips, photos) คั่นแต่ละค่าด้วย ;

ขั้น 3

Import — นำกลับเข้าระบบ

เลือกไฟล์ → กด นำเข้า · ระบบจะขึ้นเว็บจริงทันที — แนะนำลองไฟล์เล็ก 2–3 แถวก่อน ดูว่าถูกแล้วค่อยทำทีละเยอะ

ขั้น 4

เพิ่มชุดที่ยังไม่มีในระบบ

เว้นช่อง code ว่างไว้ (หรือใส่โค้ดใหม่) → ระบบจะเพิ่มเป็นชุดใหม่ให้ สถานะ needs_review รอตรวจ · ถ้าใส่ code เดิม = อัปเดตทับของเก่า

ขั้น 5

ใส่รูปด้วยคอลัมน์ photos

ช่อง photos ใส่ ลิงก์รูป (URL) ไม่ใช่ไฟล์ · หลายรูปคั่นด้วย ; เช่น .../front.jpg;.../back.jpg
รูปต้องอัปขึ้นที่เก็บสาธารณะก่อน (เช่น Supabase Storage) แล้วก็อป URL มาวาง — อย่าใช้ลิงก์ชั่วคราวที่หมดอายุ

ควรรู้ · หน้านี้บันทึกลงฐานข้อมูลจริงทันที ไม่มีขั้นพรีวิว/ย้อนกลับ · ช่อง acquisition_cost (ทุน) เป็นข้อมูลลับ ถ้ายังไม่ได้ปิดการอ่านจาก anon key แนะนำเว้นว่างไว้ก่อน กรอกแค่ rental_price
ความหมายของทุกคอลัมน์ (กรอกอะไร · ตัวอย่าง)
ป้าย จำเป็น ต้องกรอก · ลับ ข้อมูลทุน แนะนำเว้นว่าง · ฟิลด์หลายค่าคั่นด้วย ;
