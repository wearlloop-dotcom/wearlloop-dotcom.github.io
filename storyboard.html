เจนภาพ?

กดเพื่อให้ AI สร้างภาพช็อตที่เลือก โดยใช้ตัวละคร/ฉาก/reference ด้านบนแนะนำ: ตรวจว่าเลือกตัวละคร+ฉากครบก่อนกด เพราะเจนแต่ละครั้งมีค่าใช้จ่าย + มีลิมิตต่อคน/วัน
ถ้ามีข้อความในช่องนี้ตอนกดเจน ระบบจะใช้ prompt นี้แทน (รูป reference ยังแนบให้เหมือนเดิม)
กติกา: ต้องกด "ผ่าน/ไม่ผ่าน" รูปก่อนหน้าของตัวเอง ก่อนถึงจะเจนรูปใหม่ได้ — ความเห็นทุกอันเข้าระบบออดิท
ยังมีรูปที่ยังไม่ได้ตัดสิน (SHOT ) — กดผ่าน/ไม่ผ่านก่อน แล้วค่อยเจนใหม่ค่ะ

สร้าง scene ใหม่เอง เขียน prompt เองสำหรับ scene ที่ยังไม่มีในลิสต์ — ใช้นางแบบ/ชุด/สถานที่ที่เลือกด้านบน?

เขียนบรรยายเองสำหรับซีนที่ยังไม่มีในลิสต์ ระบบจะใช้ตัวละคร/ชุด/สถานที่ที่เลือกไว้แนะนำ: เขียนสั้น ชัด บอกมุมกล้อง+อารมณ์ เช่น "โคลสอัพใบหน้ายิ้ม แสงอุ่นตอนเย็น"
เลือกชุดพระเอกให้ scene นี้ (ถ้าต้องการ) — ค้นหาแล้วกดเลือก

Lookbook Studio ภาพถ่ายสตูดิโอ นางแบบ + ชุดจริงจากคลัง — ไม่ต้องอิง storyboard · แนวตั้ง 3:4?

โหมดถ่ายรูปสตูดิโอ นางแบบใส่ชุดจริงจากคลัง ไม่ต้องอิงสตอรี่บอร์ด ได้รูปแนวตั้ง 3:4 ไปโพสต์ได้เลยแนะนำ: เลือกชุดจากคลัง + นางแบบ แล้วกดเจน เหมาะทำรูปโพสต์ไอจี/ขายของ
นางแบบ = ตัวละครที่เลือกในการ์ด "ตัวละคร/นางแบบ" ด้านบน
